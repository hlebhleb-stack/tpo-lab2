# ТПО Лаб2 — Информационные системы

## Запуск

```bash
# Установить зависимости
cd bank && npm install && cd ..
cd library && npm install && cd ..

# Запустить оба сервера
bash start.sh
```

- ИС Библиотека: http://localhost:3002
